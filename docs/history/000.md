## Concepts

- **`develop.watch`**: `sync` copies changed files into the running container (no volume needed),
  `rebuild` rebuilds the image and recreates the container. Code gets synced, dependencies get rebuilt.
- **Dev and prod in one image**: the Dockerfile `CMD` is prod-style, only the compose `command` adds `--reload`.
- **Docker layers**: `pyproject.toml` + `uv.lock` are copied before the code, so a code edit doesn't invalidate the dependency layer.
- **Healthcheck** without curl: the slim image only has python, so that's what we knock with.

## How to verify

```bash
make up                                  # = docker compose up --watch, in one terminal
curl -s localhost:8000/health            # {"status":"ok"}
docker compose ps                        # STATUS: Up (healthy)
# change the response in services/harness/app/main.py, save:
# logs show "Syncing service harness" → "WatchFiles detected changes" → new process
curl -s localhost:8000/health            # the new response
cd services/harness && uv run pytest -q
```

## Knobs

| Knob | Where | What you'll see |
|---|---|---|
| healthcheck `interval` / `retries` | `compose.yaml` | how fast `ps` shows `healthy`/`unhealthy` |
| `action: sync` → `sync+restart` | `compose.yaml` | the whole container restarts instead of a uvicorn reload |
| drop `--reload` from `command` | `compose.yaml` | sync goes through, but the response doesn't change |
| add a dependency (`uv add ...`) | `services/harness` | watch sees `uv.lock` and rebuilds the image |

## Gotcha

- Starlette 1.8 (FastAPI 0.143) wants `httpx2` (a pydantic fork) in `TestClient`; plain `httpx` gives a deprecation warning.

## Questions

1. Why `sync` for `app/` and `rebuild` for `uv.lock`, and not the other way around?
   <details><summary>Answer</summary>Syncing code is cheap and reload picks it up. Dependencies live in `.venv` inside the image built for Linux; syncing the lock without `uv sync` is useless, the layer has to be rebuilt.</details>
2. What breaks if you swap the `COPY` order in the Dockerfile (all code first, then `uv sync`)?
   <details><summary>Answer</summary>Nothing functionally, but every code edit invalidates the dependency layer, and each rebuild reinstalls everything.</details>
